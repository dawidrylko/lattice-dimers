# Tests

Each language tests itself on the shared data: [`spec/cases/`](../spec/cases/README.md), [`spec/limits.json`](../spec/limits.json) and [`spec/cli.json`](../spec/cli.json). The tests take a short run by default, and `FULL_CASES=1` runs every known term.

A short run stops `domino-rectangle-bigint` and `domicule-rectangle-bigint` at the 16 × 16 square and `all-lattices-cylinder-torus-bigint` at the 8 × 8 torus. `all-lattices-cylinder-torus-modular`, `all-lattices-rectangle-modular`, `domicule-rectangle-polynomial-modular` and `domicule-cylinder-torus-polynomial-modular` run their first seven cases and the boards of their BigInt twins.

The commands below run in CI on each pull request, in this order, apart from `pnpm -C js test:render`, which is part of `pnpm -C js test` and runs alone only on macOS. CI also runs `cargo clippy --workspace --all-targets -- -D warnings`. `pnpm -C js test:benchmarks` needs the Rust binaries of `cargo test --release` and the Python package. To pick tests, use `--test-name-pattern` in `node --test` and `-k` in pytest; a filter in `cargo test` picks a whole group of the Rust tests.

| `pnpm -C js site:build` | [`../site/build.js`](../site/build.js) | runs every notebook cell in [`notes/`](../notes/README.md); a cell that checks a result against the data stops the build when they disagree. CI starts it from another directory |

[REGRESSIONS.md](REGRESSIONS.md) lists every defect fixed so far, the check that fails if it comes back, and how that was shown.

`FULL_CASES=1` runs every known term in any of the three languages. It takes hours in JavaScript and Python, the 16 × 16 torus alone about 75 minutes, and runs outside CI.

The CI job `Research` runs the Python checks of [`research/king-entropy`](../research/king-entropy/README.md): `src/test_paths.py`, `src/test_timed.py`, `src/test_regressions.py`, reruns of `src/derived.py`, `src/errbar.py`, `src/hidden_oos.py`, `src/lspec.py` and `src/ltest.py` against their files in `out/` and of `replication/analyze_eig.py` and `replication/compare_eig.py` against theirs in `replication/out/`, and the syntax of `.zenodo.json`.

The CI job `macOS` runs `js/test/render.test.js`, `src/test_timed.py` and the rerun of `src/lspec.py` again on macOS, where a pipe takes output asynchronously, `ru_maxrss` is in bytes and LAPACK is another build.
