Number of domicule tilings of a 2n X 2n cylindrical grid.

DATA

OFFSET

0,2

COMMENTS

For n > 1, a(n) is the number of perfect matchings of the strong product P_2n X C_2n, which is the king's graph on the 2n X 2n cylinder. For n = 1 the cylinder has multiple edges, and each of them counts as a separate piece, as in A401670.

LINKS

Dawid Ryłko, <a href="/A402163/b402163_1.txt">Table of n, a(n) for n = 0..11</a>

Dawid Ryłko, <a href="https://dawidrylko.github.io/lattice-dimers/notes/domicules/cylinders.html">Domicules: tilings of cylinders</a>.

EXAMPLE

a(1) = 9: on the 2 X 2 cylinder each cell is joined to its row neighbor by 2 edges, to its column neighbor by 1 edge and to the diagonal cell by 2 edges, so a(1) = 2*2 + 1*1 + 2*2 = 9.

PROG

(PARI) \\ M(w): row transfer matrix of the cylinder of circumference w; a(n) goes from the empty row to the empty row.

R(w, c, f, t) = {my(v = []); if(c == w, return([t])); if(bittest(f, c), return(R(w, c+1, f, t))); if(c+1 < w && !bittest(f, c+1), v = concat(v, R(w, c+2, f + 2^c + 2^(c+1), t))); if(c == 0 && !bittest(f, w-1), v = concat(v, R(w, 1, f + 1 + 2^(w-1), t))); for(d = -1, 1, my(j = (c+d) % w); if(!bittest(t, j), v = concat(v, R(w, c+1, f + 2^c, t + 2^j)))); v};

M(w) = {my(A = matrix(2^w, 2^w)); for(f = 0, 2^w-1, my(v = R(w, 0, f, 0)); for(i = 1, #v, A[f+1, v[i]+1]++)); A};

a(n) = (M(2*n)^(2*n))[1, 1];
