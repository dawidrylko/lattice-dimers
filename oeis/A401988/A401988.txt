%N A401988 Number of perfect matchings in the 2n X 2n grid graph with the diagonal edges from (i,j) to (i+1,j+1) added, i.e., in a 2n X 2n rhombus of the triangular lattice.
%C A401988 Equivalently, the number of tilings of the 2n X 2n square by dominoes and by diagonal pieces that join two cells sharing a corner, where all diagonal pieces run in the same direction. Compare A239273, where both directions are allowed.
%C A401988 The graph is planar, so a(n) = |Pf(K)| = sqrt(det(K)) for the Kasteleyn matrix K of the PARI program. A transfer matrix in exact integers gives the same terms.
%H A401988 Dawid Ryłko, <a href="/A401988/b401988_2.txt">Table of n, a(n) for n = 0..37</a>
%H A401988 Paul Fendley, R. Moessner and S. L. Sondhi, <a href="https://doi.org/10.1103/PhysRevB.66.214513">Classical dimers on the triangular lattice</a>, Phys. Rev. B 66 (2002), 214513.
%H A401988 Dawid Ryłko, <a href="https://dawidrylko.github.io/lattice-dimers/notes/triangular-lattice/rectangles.html">Triangular lattice: rectangles</a>.
%F A401988 lim_{n->oo} log(a(n))/(4*n^2) = 0.42859453746..., the dimer entropy per site of the triangular lattice (Fendley, Moessner and Sondhi).
%e A401988 a(1) = 2: the 2 X 2 board has only the diagonal from (1,1) to (2,2), and using it leaves (1,2) and (2,1), which are not adjacent, so only the two domino tilings remain.
%o A401988 (PARI) \\ K: Kasteleyn matrix of the board; edges (1, 0) and (0, 1) from even x get sign -1, all others +1.
%o A401988 a(n) = {my(L = 2*n, K = matrix(L^2, L^2), D = [1, 0; 0, 1; 1, 1]); if(n == 0, return(1)); for(x = 0, L-1, for(y = 0, L-1, for(k = 1, 3, my(x2 = x + D[k, 1], y2 = y + D[k, 2], s); if(x2 < L && y2 < L, s = if(k < 3 && x%2 == 0, -1, 1); K[x*L+y+1, x2*L+y2+1] = s; K[x2*L+y2+1, x*L+y+1] = -s)))); sqrtint(matdet(K))};
