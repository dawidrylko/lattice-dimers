%N A402693 Number of perfect matchings in the 2n X 2n cylindrical grid graph P_2n X C_2n with the diagonal edges from (i,j) to (i+1,j+1 mod 2n) added, i.e., on a 2n X 2n cylinder of the triangular lattice.
%C A402693 For n >= 2 the graph is simple. For n = 1 the cycle C_2 has two edges between its two vertices, and each of them counts as a separate domino, as in A402163 and A402345.
%C A402693 Equivalently, the number of tilings of the 2n X 2n cylinder by dominoes and by diagonal pieces that join two cells sharing a corner, where all diagonal pieces run in the same direction. Compare A401988, the same board without the seam.
%H A402693 Dawid Ryłko, <a href="/A402693/b402693_1.txt">Table of n, a(n) for n = 0..36</a>
%H A402693 Dawid Ryłko, <a href="https://dawidrylko.github.io/lattice-dimers/notes/triangular-lattice/cylinders.html">Triangular lattice: tilings of cylinders</a>.
%H A402693 Eric Weisstein's World of Mathematics, <a href="https://mathworld.wolfram.com/PerfectMatching.html">Perfect Matching</a>.
%F A402693 Limit_{n->oo} log(a(n))/(4*n^2) = log(A247548)/2.
%e A402693 a(1) = 6: on the 2 X 2 cylinder each cell is joined to its row neighbor by 2 edges, to its column neighbor by 1 edge and to its diagonal neighbor by 1 edge, so a(1) = 2*2 + 1*1 + 1*1 = 6.
%o A402693 (PARI) \\ K: Kasteleyn matrix of the cylinder, with the edges across the seam negated when f = 1; the larger |det(K)| is a(n)^2.
%o A402693 a(n) = {my(L = 2*n, d = 0, D = [1, 0; 0, 1; 1, 1]); if(n == 0, return(1)); for(f = 0, 1, my(K = matrix(L^2, L^2)); for(x = 0, L-1, for(y = 0, L-1, for(k = 1, 3, my(x2 = x + D[k, 1], y2 = y + D[k, 2], s); if(x2 < L, s = if(k < 3 && x%2 == 0, -1, 1) * if(f && y2 == L, -1, 1); y2 %= L; K[x*L+y+1, x2*L+y2+1] += s; K[x2*L+y2+1, x*L+y+1] -= s)))); d = max(d, abs(matdet(K)))); sqrtint(d)};
