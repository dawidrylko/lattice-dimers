%N A402163 Number of domicule tilings of a 2n X 2n cylindrical grid.
%C A402163 For n > 1, a(n) is the number of perfect matchings of the strong product P_2n X C_2n, which is the king's graph on the 2n X 2n cylinder. For n = 1 the cylinder has multiple edges, and each of them counts as a separate piece, as in A401670.
%C A402163 Terms a(0)-a(7) agree between two transfer-matrix programs, one by rows in exact integers and one by cells modulo primes. Terms a(8)-a(11) agree between two independent programs by cells modulo primes; each uses enough primes for an upper bound on the number of perfect matchings, so the Chinese remainder theorem gives the exact count.
%H A402163 Dawid Ryłko, <a href="/A402163/b402163_1.txt">Table of n, a(n) for n = 0..11</a>
%H A402163 Dawid Ryłko, <a href="https://dawidrylko.github.io/lattice-dimers/notes/domicules/cylinders.html">Domicules: tilings of cylinders</a>.
%F A402163 a(n) = (M_{2n}^(2n))[0,0], where M_w is the row transfer matrix of domicule tilings of the cylinder of circumference w and index 0 is the empty row (see PARI program).
%e A402163 a(1) = 9: on the 2 X 2 cylinder each cell is joined to its row neighbor by 2 edges, to its column neighbor by 1 edge and to the diagonal cell by 2 edges, so a(1) = 2*2 + 1*1 + 2*2 = 9.
%o A402163 (PARI) \\ M(w): row transfer matrix of the cylinder of circumference w; a(n) goes from the empty row to the empty row.
%o A402163 R(w, c, f, t) = {my(v = []); if(c == w, return([t])); if(bittest(f, c), return(R(w, c+1, f, t))); if(c+1 < w && !bittest(f, c+1), v = concat(v, R(w, c+2, f + 2^c + 2^(c+1), t))); if(c == 0 && !bittest(f, w-1), v = concat(v, R(w, 1, f + 1 + 2^(w-1), t))); for(d = -1, 1, my(j = (c+d) % w); if(!bittest(t, j), v = concat(v, R(w, c+1, f + 2^c, t + 2^j)))); v};
%o A402163 M(w) = {my(A = matrix(2^w, 2^w)); for(f = 0, 2^w-1, my(v = R(w, 0, f, 0)); for(i = 1, #v, A[f+1, v[i]+1]++)); A};
%o A402163 a(n) = (M(2*n)^(2*n))[1, 1];
